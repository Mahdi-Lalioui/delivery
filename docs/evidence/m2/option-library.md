# M2 reusable option library evidence

The production `pnpm test:e2e:auth --fail-on-flaky-tests` suite passed all 11 Chromium journeys. The option journey creates bilingual choices, verifies whole-DZD price deltas and independent default and sold-out flags, and saves the same group on two items. It reorders one item's attachments with the keyboard, edits the shared group without changing option IDs, and verifies both items after reopening. The French picker has a 44 px minimum target.

The design critic approved 24 Arabic and French light and dark views at 390×844, 768×1024 and 1280×800, plus eight 360×844 views at 200% text size. All 32 passed the axe WCAG A and AA and layout checks. Each currency suffix remained on one line. The picker kept a visible 1 px border and 44 px height.
