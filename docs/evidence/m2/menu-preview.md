# M2 saved-menu preview and demo seed

The authenticated merchant preview reads only the saved menu for owners and managers. PostGIS cases cover blocked, rejected and archived rows, legacy unsafe text, wrong tenants, revision and cursor conflicts, available variants and ordered options. The production browser proved a clean item and its options appear while a held item and direct detail stay hidden. The same journey proved the reviewed alcohol-free item appears after approval. The item lifecycle checked a real ready photo through the private variant route.

The editor and import freeze held text. Later holds require a token tied to the reviewed content and cycle. PostGIS reproduced both stale paths before the fixes. The security reviewer found no remaining bypass. [Lane B client handoff](../../requests/lane-a-moderation-token.md)

The 12 preview captures cover Arabic and French, both themes, and 390×844, 768×1024 and 1280×800. The browser checks axe and overflow. The lead inspected phone and desktop in both languages and the design critic passed the preview. [Captures](menu-preview/)
