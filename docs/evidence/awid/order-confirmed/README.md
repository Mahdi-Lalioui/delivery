# AWID order confirmation

Open `/fr/dev/gallery?screen=checkout` in the design build and select ✓ in the checkout sample. The live screen opens after a successful order and moves to its tracking page.

In the first pass, the opened lid was clipped, the light bleached the couscous, the pattern competed with the headline, the dark-mode order reference lost its pill, and the static lid knob floated above the lid. The second pass widened the camera, softened the lighting and pattern, restored the reference contrast, and joined the knob to the lid. The same check exposed a blocked server-rendered style on the courier slider in the gallery. The resting thumb now uses CSS and only receives a dynamic transform during interaction.

The final Chromium captures kept the tracking action in the viewport and produced no console errors or horizontal overflow. The dark desktop capture uses the static reduced-motion illustration.
