# Search — round 1 flaws

Captured on the real search dialog (`/[locale]/discover?search=open`), empty and with
"chawarma". Compared with Deliveroo and Uber Eats search.

1. **Photos.** Dish results show placeholder plates although every dish has a photo.
2. **Header.** A display-size title and a two-line intro push the field down; top apps open
   search with the field at the top.
3. **Focus.** The input draws its own focus box inside the pill (double border).
4. **Empty state.** Before typing, only four text chips; browsing by cuisine with photos is
   missing.
5. **Copy.** "Explore … of Algiers" while AWID covers all of Algeria.
